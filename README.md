# Adivinha a Palavra 🇧🇷

Um jogo estilo Wordle em português. Você tem 6 tentativas para descobrir uma
palavra de 5 letras.

- 🟩 verde = letra certa, posição certa
- 🟨 amarelo = letra existe, posição errada
- ⬛ cinza = letra não existe na palavra

## Como jogar

Basta abrir o `index.html` no navegador (duplo clique) — não precisa de
servidor nem instalação. Digite pelo teclado físico ou clique no teclado
virtual na tela. Use Enter para confirmar e Backspace/⌫ para apagar.

Clique no ícone 🔄 no topo (ou "Jogar novamente" ao final) para começar uma
nova palavra.

## Arquivos

- `index.html` — estrutura da página
- `style.css` — visual (tema escuro, tiles animados)
- `script.js` — lógica do jogo e lista de ~70 palavras em português
